# 🚗 Auto Car - Bosch Car Service Montes Claros

Site institucional de alta precisão e performance desenvolvido para o centro automotivo **Auto Car Bosch Car Service** em Montes Claros - MG.

Construído com **Next.js 16 (App Router)**, **TypeScript** e **Design Responsivo Avançado (Mobile-First)**, otimizado para deploy instantâneo na **Vercel** e indexação máxima no Google (SEO Local & Schema.org).

---

## 🌟 Destaques do Projeto

- **Design Premium & Clean**: Identidade visual moderna inspirada em padrões internacionais de centros automotivos, utilizando as cores oficiais Bosch (Azul Bosch `#005696`, Vermelho Bosch `#E30613` e Branco Puro).
- **Auto Diagnóstico Rápido Interativo**: Simulador de sintomas mecânicos onde o motorista identifica problemas (injeção acesa, trepidação no volante, ar fraco, ruído de freios) e recebe a análise técnica recomendada.
- **Integração Direta com WhatsApp**: Geração automática de mensagens formatadas enviadas diretamente para a central de atendimento oficial da oficina `(38) 3214-7590`.
- **Experiência Mobile-First**:
  - Reordenação inteligente de seções no celular (Diagnóstico Rápido exibido no topo).
  - Prevenção total de scroll lateral e alinhamento milimétrico em dispositivos modernos (como iPhone 16).
  - Botões com altura unificada de 48px e área de toque ergonômica para polegar.
  - Barra de ações rápidas flutuante fixa no rodapé do mobile.
- **SEO Local & Rich Snippets**:
  - Metadados completos com Open Graph, Twitter Cards e Geo-tags de Montes Claros - MG (`-16.731771; -43.864178`).
  - Marcação estruturada completa `Schema.org/AutoRepair` com horário de funcionamento, serviços e telefones.
  - `sitemap.xml` e `robots.txt` gerados dinamicamente.
- **Carrossel Histórico**: Seção especial de legado familiar prestando homenagem ao fundador Sr. Edmar (Batata) desde a década de 1970 até a atual fase homologada Bosch.

## 🛠️ Tecnologias Utilizadas

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Linguagem**: [TypeScript](https://www.typescriptlang.org/)
- **Estilização**: Vanilla CSS + CSS Modules / Scoped JSX (Tokens de Design HSL & Hex)
- **Ícones**: [Lucide React](https://lucide.dev/)
- **Otimização de Imagens**: `next/image` com suporte a WebP e prioridade de carregamento
- **Deploy**: Preparado para [Vercel](https://vercel.com/) com rotas 100% estáticas pré-renderizadas

## 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone git@github.com:CaioMAS/autoCar.git
cd autoCar
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

---

## 📦 Build de Produção

Para testar a compilação estática de produção:
```bash
npm run build
npm start
```
